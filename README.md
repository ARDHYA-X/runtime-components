# runtime_components

A small git repository for practicing version control basics in CS 18000 at Purdue. It holds shell configuration files that set up my terminal environment.

## Contents

- `README.md`: this file, describing the repository
- `.bashrc`: shell configuration that bash reads every time an interactive terminal opens

## Usage

To apply the `.bashrc` settings to a running terminal:

    source ~/.bashrc
